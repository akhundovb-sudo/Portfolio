Best Practice

  • Use only one primary button per section or screen.
  • Don’t disable a button without providing context.
  • Avoid using too many variants together.
  • Keep labels short and actionable (“Save”, “Continue”).

Don’ts

  • Don’t use primary and destructive buttons side by side.
  • Don’t use buttons for navigation (use links for that).
  • Avoid placing multiple loading buttons on one screen.
